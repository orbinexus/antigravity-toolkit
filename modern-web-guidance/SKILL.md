# Modern Web Standards & Platform Guidance

This skill guides the use of modern browser platform APIs, zero-framework HTML/CSS enhancements, and standards-compliant web development.

## 1. Modern CSS Features

- **Container Queries (`@container`)**: Style components based on their parent container's width rather than global viewport media queries.
- **CSS Grid Subgrid (`grid-template-rows: subgrid`)**: Align nested cards and list items across complex parent layouts.
- **CSS `:has()` Pseudo-class**: Style ancestor elements based on child state without JavaScript mutation observers.

## 2. Modern Native Web APIs
- **Web Storage & File System Access**: `window.showOpenFilePicker` and Origin Private File System (OPFS) for ultra-fast local disk access.
- **View Transitions API**: Smooth page-to-page morphing animations native to the browser without third-party animation libraries.
