# Developer Documentation & API Portal Architect

This skill directs the creation of developer-focused documentation hubs, interactive API references, and SDK quick-start portals modeled after Stripe, Supabase, and Vercel standards.

## 1. Documentation Structure & Information Architecture

1. **Information Hierarchy**:
   - **Quickstart / 5-Minute Guide**: Minimal path to get first "Hello World" or successful API response.
   - **Concepts / Architecture**: Mental models, lifecycle states, and core abstractions.
   - **API Reference**: Autogenerated or OpenAPI-synchronized endpoints with parameters, headers, and response payloads.
   - **Cookbook / Tutorials**: Practical real-world recipes solving common production problems.
2. **Interactive Component Integration**:
   - Multi-language code snippets with copy buttons (cURL, TypeScript, Python, Go).
   - Embedded interactive API playgrounds allowing live token testing.
   - Visual callouts (tips, warnings, version badges) and clean step-by-step numbered walkthroughs.
